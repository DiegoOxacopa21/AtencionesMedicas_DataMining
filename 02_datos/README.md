# 02_datos - Entendimiento de Datos

## Propósito
Recopilación de datos crudos, documentación de fuentes y descripción del dataset.

## Subcarpetas
- `raw/`: Datos crudos originales (NO modificar)
- `plantilla_documento/`: Plantilla LaTeX para reportes técnicos

## Contenido esperado
- Datos originales en formato CSV, Excel, JSON, etc.
- Documentación de fuentes y metadatos
- Plantilla de documento (CSMakotoTechnicalReport)

## Convenciones
- Datos crudos: nunca modificar en `raw/`
- Trabajar con copias en `data/` o carpetas de proceso
- Documentar cambios y transformaciones

## Archivos relevantes
- `README.md` (este archivo)
- `raw/` (datos originales)
- `plantilla_documento/template.tex` (plantilla reportes)
