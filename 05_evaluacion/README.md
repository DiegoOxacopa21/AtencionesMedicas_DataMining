# 05_evaluacion - Evaluación

## Propósito
Evaluación de modelos, generación de reportes y documentación de resultados.

## Subcarpetas
- `reports/`: Reportes (PDF, LaTeX, HTML)

## Contenido esperado
- Métricas de evaluación por modelo

- Visualizaciones y gráficos
- Reportes formales (LaTeX)

## Formato de reportes
- Usar LaTeX para reportes formales
- Naming: `reporte_v{VERSION}_{FECHA}.tex`
